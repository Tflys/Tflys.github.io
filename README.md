# Currículum - Francisco Alabarce Ortiz

Este es un repositorio que contiene mi currículum interactivo y actualizado, el cual incluye información sobre mi experiencia académica, habilidades, proyectos y logros. Este proyecto está diseñado para mostrar tanto mis habilidades de desarrollo web como mi experiencia en el sector empresarial.

## Descripción

Soy estudiante de **Desarrollo de Aplicaciones Web (DAW)** y busco una oportunidad para realizar prácticas en una empresa que me permita aplicar mis conocimientos y seguir aprendiendo. A lo largo de mi carrera, he adquirido experiencia en diversas áreas de desarrollo web, programación backend, diseño de interfaces y gestión de proyectos. Además, soy **fundador y gerente general** de una pequeña empresa de multiservicios, lo que me ha permitido desarrollar habilidades de gestión, liderazgo y toma de decisiones.

Este repositorio contiene:
- **Currículum interactivo**: Usando HTML, CSS y JavaScript.
- **Proyectos destacados**: Muestra de trabajos realizados durante mis estudios en DAW.
- **Certificaciones**: Certificados obtenidos que respaldan mis conocimientos en tecnologías clave.

## Tecnologías Usadas

- **Lenguajes de Programación**: JavaScript, PHP, Python, Java
- **Lenguajes de Marcas**: HTML, CSS, XML
- **Bases de Datos**: MySQL, PostgreSQL
- **Frameworks**: Laravel, React
- **Herramientas**: Docker, Git, Visual Studio Code
- **Formatos de Datos**: JSON
- **Otros**: Diseño de interfaces, desarrollo de API REST
